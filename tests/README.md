# omarchy-zh-cn 测试套件

此目录包含面向本项目的自动化静态检查、隔离集成测试与安装卸载生命周期测试。

## 测试脚本

- `smoke.sh`：快速烟雾测试。执行 Shell 语法校验、Python AST 语法解析、单元测试、个人隐私路径泄露检查、关键翻译断言与 ShellCheck 静态分析，并在最后级联触发集成与周期测试。
- `integration.sh`：隔离集成测试。在隔离沙箱环境中测试 `omarchy-zh-sync` 的插件生成、元数据标记、菜单提取、Qt/Node 本地化格式化逻辑及防御机制。
- `install-cycle.sh`：安装与卸载全生命周期测试。在沙箱文件系统与 Mock 工具链下完整模拟安装、备份、覆写、配置合并、卸载还原与断言校验。

## 执行方法

```bash
./tests/smoke.sh
```
