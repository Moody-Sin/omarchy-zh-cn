# omarchy-zh-cn 可执行命令

此目录包含 `omarchy-zh-cn` 的核心同步与更新控制脚本。

## 目录内容

- `omarchy-zh-sync`：核心本地化同步器。基于系统当前安装的 Omarchy 4 源码动态生成用户级插件克隆，应用汉化补丁，并维护菜单与快捷键本地化配置。
- `omarchy-update-zh`：中文更新流程包装器。在安全独立的私有环境下调用本地化后的 Omarchy 系统更新脚本。
- `omarchy-update-confirm-zh`：中文交互式更新确认工具。基于 `gum` 提供格式化的终端提示与二选一确认交互。

## 约定与权限

- 脚本均需具备可执行权限（`chmod 755`）。
- 绝不在脚本中硬编码用户名或个人绝对路径。
